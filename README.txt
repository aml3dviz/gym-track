GYMTRACK V4 — INSTALACIÓN

1. Extraé el ZIP.
2. Creá un repositorio PÚBLICO en GitHub.
3. Subí todos los archivos directamente a la raíz del repositorio (no la carpeta contenedora).
4. Settings > Pages > Deploy from a branch > main > /(root).
5. Abrí la URL de GitHub Pages en Safari (iPhone) > Compartir > Agregar a pantalla de inicio.

FUNCIONES: registro de series/pesos/reps, descanso en segundos, comparación con sesión anterior, edición de rutinas, reemplazo de ejercicios por el día, historial, progreso, calendario mensual de asistencia, fisioterapia, ausencias, días libres, sesiones extras, planes configurables y backup JSON.

IMPORTANTE: Los datos se guardan en el navegador de cada dispositivo. No hay sincronización automática. Exportá backups periódicamente. El calendario permite marcar asistencia/ausencia manualmente. El porcentaje excluye pendientes y sesiones extra.
